Веб-панель для плагина [Verdict](https://github.com/whyn0tq/cs2-verdict): баны, муты и админы серверов CS2 из браузера. Работает на обычном хостинге с PHP и MySQL.

- **Схема Material Admin.** Таблицы `sb_bans`, `sb_comms`, `sb_admins`, `sb_srvgroups`, `sb_servers`. Базу Material Admin или SourceBans можно подключить как есть, старые логины и пароли админов подходят.
- **Одна база с плагином.** Панель и плагин общаются только через неё — открывать порты на игровом сервере не нужно.
- **Свои данные отдельно.** Права панели, 2FA, журнал и живые данные лежат в таблицах `vd_*` и не мешают другим панелям и плагинам.

## Возможности

| | |
|---|---|
| Наказания | бан по SteamID и IP, мут, гаг, сайленс: выдача, правка, снятие, поиск |
| Админы | флаги, иммунитет, группы, срок действия, привязка к серверам, лимиты группы на срок бана и мута |
| Серверы | статус, карта, игроки, RCON-консоль, несколько серверов в одной панели |
| Онлайн | табло и чат, кик, смена команды, убийство, сообщения в чат (нужен плагин) |
| Игроки | аватары и профили Steam, поиск по SteamID, ссылке на профиль или короткому имени |
| Безопасность | двухфакторный вход TOTP, журнал действий админов |
| Другое | мастер установки, языки ru / en, светлая и тёмная тема |

## Требования

| Что | Подробности |
|---|---|
| PHP | 5.2+, рекомендуется 7.4+ (проверено на 8.3) |
| База данных | MySQL 5.5.3+ / MariaDB 10+ |
| Веб-сервер | Apache с поддержкой `.htaccess` |
| Игровой сервер | [плагин Verdict](https://github.com/whyn0tq/cs2-verdict) с удалённым доступом к этой же базе |

## Установка

1. Скачайте панель (*Code* → *Download ZIP* или релиз) и загрузите все файлы, включая `.htaccess`, на хостинг по FTP — в корень сайта или в подпапку.
2. Поставьте на папку `data` права `777`.
3. Подготовьте базу MySQL или используйте готовую от Material Admin или admin_system.
4. Откройте сайт. Мастер установки проверит PHP и попросит код из файла `data/install-code.php`.
5. Укажите данные базы и префикс таблиц (`sb`, как `database_prefix` в `core.ini` плагина), создайте аккаунт владельца и добавьте первый сервер.
6. В конце мастер покажет готовые блоки для `addons/configs/databases.cfg` и `addons/configs/verdict/core.ini`. Скопируйте их на игровой сервер и перезапустите его.

Чтобы запустить мастер заново, удалите `data/config.php`.

### Доступ игрового сервера к базе

Включите удалённый доступ к MySQL в панели хостинга (cPanel — *Remote MySQL*), добавьте IP игрового сервера и укажите внешний адрес MySQL вместо `localhost` в поле `host` файла `databases.cfg`. Пользователю базы нужны полные права: плагин сам создаёт недостающие таблицы.

## Связь с плагином

- Если в `core.ini` указан `server_id`, плагин каждые несколько секунд пишет в базу онлайн, счёт и чат — на странице сервера появятся живое табло и чат.
- Кик, смена команды, убийство и сообщения из панели идут через очередь и выполняются в течение секунды.
- Баны, муты и админы, выданные в панели, плагин подхватывает без перезапуска.
- Без плагина панель показывает статус и игроков через A2S, а RCON работает, если указан пароль.

Админов из cs2-admin_system импортирует плагин: `vd_import as_` в консоли игрового сервера.

## Обновление

Сделайте копию `data`, загрузите новые файлы поверх старых, `data` не удаляйте, откройте панель — новые таблицы и поля создадутся сами.

## Частые проблемы

| Проблема | Что сделать |
|---|---|
| Нет прав на запись в `data` | поставьте права `777` |
| Ошибка 500 или белый экран | проверьте версию PHP и журнал ошибок хостинга |
| Мастер не подключается к базе | возьмите адрес, имя базы и пользователя из раздела «Базы данных»; к имени часто добавляется префикс аккаунта (`user_verdict`) |
| Плагин не подключается | не включён удалённый доступ к MySQL или в `databases.cfg` стоит `localhost` |
| Сервер «не отвечает», плагин работает | хостинг закрывает исходящий UDP — укажите `server_id` в `core.ini` |
| Файлы из `data` или `includes` открываются в браузере | хостинг не читает `.htaccess` — напишите в поддержку |

Включите HTTPS и двухфакторный вход, не публикуйте `data/config.php` и код установки.
